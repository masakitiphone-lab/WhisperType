# サポート・データ削除ページ草案

最終更新日: 2026年5月6日

## サポート

WhisperTypeに関するお問い合わせは、以下のメールアドレスまでご連絡ください。

- メール: studiomirai.info@gmail.com
- 運営: Studio Mirai

お問い合わせの際は、以下を含めてください。

- 利用しているOS
- WhisperTypeのバージョン
- 発生している問題
- エラーメッセージがある場合はその内容
- Plus課金に関する問い合わせの場合は、Microsoft Storeで管理しているサブスクリプション状況

パスワード、認証コード、支払いカード番号などの機密情報は送信しないでください。

## Plus課金に関する問い合わせ

WhisperType PlusはMicrosoft Storeのサブスクリプションとして提供されます。購入、更新、解約、返金はMicrosoft Storeの仕組みに従います。

解約は、MicrosoftアカウントまたはMicrosoft Storeのサブスクリプション管理画面から行ってください。

## データ削除・アカウント削除

アカウント削除機能がアプリ内に提供されている場合は、アプリ内のアカウント削除機能を利用してください。

アプリ内削除機能が未実装または利用できない場合は、以下の内容をメールで送信してください。

- 件名: WhisperType data deletion request
- WhisperTypeにログインしているメールアドレス
- 削除を希望する内容: アカウント削除、文字起こし履歴削除、その他

本人確認のため、追加情報の確認をお願いする場合があります。

削除対象には、プロフィール情報、文字起こし履歴、利用回数情報が含まれます。ただし、法令、課金、不正利用防止、紛争対応のために必要な情報は、必要な期間保存する場合があります。
